04 — Agent Design Lessons

What this teaches us about
building autonomous agents

Eight patterns transferable to Amy, Eva, Vio, and any autonomous AI system.

01
Principle

Never Let the Agent Judge Itself

evaluate_bpb is in read-only prepare.py. The agent physically cannot modify its success metric. For any autonomous system: the judge must be immutable and external.

02
Pattern

Constraints Enable Autonomy

One mutable file. Fixed time budget. No new dependencies. These limits make autonomous operation possible. More freedom = more coordination = more human checkpoints needed.

03
Pattern

Git = Free State Machine

Commit = checkpoint. Reset = rollback. Branch = experiment track. No custom database needed. Entire experiment history is auditable via git log.

04
Principle

Time-Box Everything

Every experiment is exactly 5 minutes. Makes results directly comparable regardless of what the agent changed. Without time budgets, experiments can't be compared.

05
Principle

"NEVER STOP" = True Autonomy

program.md explicitly says: "Do NOT ask 'should I continue?'" The human might be asleep. Every permission prompt is a design failure. Requires: clear metrics + bounded risk + auto-recovery.

06
Pattern

Encode Quality as Decision Rules

"0.001 improvement + 20 lines of hack? Not worth it. Equal result + deleted code? Keep." Concrete heuristics, not aspirational statements. Agents follow rules, not vibes.

07
Pattern

program.md = The New Programming

Humans write strategy in Markdown. AI writes code. This maps to our SOUL.md / FA.md / DAO.md. The quality of instructions determines the quality of output.

08
Gap

No Cross-Experiment Learning

Each experiment is independent. No Bayesian optimization, no meta-learning, no memory of what worked. This is where our claudemem stack is ahead.

06 — Verdict

Conceptually brilliant,
practically limited

★ 8.5 / 10

The value is the idea, not the code

Autoresearch proves that the fundamental loop of scientific research — hypothesize, experiment, evaluate, iterate — can be fully automated with today's LLMs. Its genius is in the constraints: one file, one metric, five minutes, zero checkpoints. These constraints are what make autonomy possible. The limitation is that it's a proof of concept: GPU-only, single metric, no cross-experiment learning, single agent. The real frontier is adding persistent memory, multi-agent coordination, and adaptive search strategies — which is exactly where our stack is already positioned.

07 — Five Takeaways
1

Strategy > Code

program.md is the product. train.py is the output. Write better instructions, get better research.

2

Limits = Freedom

One file, one metric, five minutes. These constraints make autonomous operation possible.

3

Immutable Judge

The agent cannot modify evaluate_bpb. We need equivalent quality gates.

4

5

Memory is the Edge
